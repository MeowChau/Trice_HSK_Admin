# Thư mục chứa tài nguyên Giáo trình & Sách bài tập (Trice HSK)

Bạn có thể thả các file tài nguyên giáo trình và sách bài tập vào các thư mục tương ứng dưới đây:

### 1. `backend/data/workbooks/` (Sách bài tập)
- Chứa các file PDF hoặc Word của sách bài tập (ví dụ: `Workbook_HSK1.pdf`, `HSK2_Lianxice.pdf`,...).
- Sẽ dùng để bóc tách đề luyện tập (Practice Sets), câu hỏi đọc hiểu, câu hỏi ngữ pháp.

### 2. `backend/data/textbooks/` (Sách giáo trình)
- Chứa các file PDF hoặc Word giáo trình chuẩn HSK (ví dụ: `HSK1_Standard_Course.pdf`,...).
- Dùng để bóc tách bài khóa, cấu trúc ngữ pháp, từ vựng theo bài học.

### 3. `backend/data/audio/` (File âm thanh luyện nghe)
- Chứa các file audio `.mp3` hoặc `.wav` phục vụ phần thi Nghe (Listening).
- Khuyến khích đặt tên theo bài học (ví dụ: `HSK1_Lesson_01.mp3`, `HSK1_Lesson_02.mp3`, `HSK1_MockTest.mp3`).

### 4. `backend/data/excel_json/` (Dữ liệu bảng biểu đã soạn sẵn nếu có)
- Chứa các file `.xlsx`, `.csv`, hoặc `.json` nếu bạn đã có sẵn danh sách câu hỏi, đáp án, giải thích chi tiết hoặc từ vựng theo cột.
